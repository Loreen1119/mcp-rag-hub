# TiDB 语料入库记录（2026-10-13）

> 本文件只记录数据入库阶段的事实、口径与决策；评测集设计、基线、消融均不在本阶段范围内。

## 一、总体结论

- 三源中文语料已全部落盘到 `corpora/tidb/`：**9169 篇 / 39.4 M 字符 / 约 21.4 M token / 约 9.8 万 chunk**（chunk_size=256、overlap=38、步长 218 口径，按 300 篇抽样外推，token/字符 = 0.543）。
- 🔴 **口径修正**：原方案估的「docs-cn 双版本差异页约 1.1~1.2 万文档」比实测高两个数量级。docs-cn 全站 md 只有 1350 篇（release-8.5），8.4↔8.5 的达标差异页是 **306 篇**。语料体量实际由 AskTUG 与社区专栏构成，不是官方文档。
- **规模维持现状（2026-10-14 定稿）**：不压缩、不截断，对外口径写实测值「**约 1 万文档 / 近 10 万 chunk**」。
- **入库方式**：`corpora/tidb/` 整目录写进 `.gitignore`，不进公开仓库；公开仓库只留抓取脚本与来源声明。

## 二、各源计数

### docs-cn（官方文档）

- 落点 `corpora/tidb/docs-cn/`：**1318 篇 / 16 MB / 9.17 M 字符**
- 来源：`github.com/pingcap/docs-cn`，分支 `release-8.5`（当前最新稳定版；无 8.6 / 9.x 分支）
- 剔除 32 篇：`.agents/`、`.github/`、`.vaunt/`、`CONTRIBUTING.md`、`README.md`、`_` 前缀文件、`TOC*` 导航页
- 许可：**CC BY-SA 3.0**（要求署名 + 相同方式共享；与 fastapi-zh 的 MIT、vue-zh 的 CC BY 4.0 都不同）
- 改动：正文一字未改，目录结构原样保留

### docs-cn-v8.4（版本差异页的旧版正文）

- 落点 `corpora/tidb/docs-cn-v8.4/`：**306 篇 / 5.1 MB / 3.19 M 字符**
- 判定口径：与 `release-8.4` 同名文件逐行 diff，**先剔除「整行纯版本号」与「整行纯 URL」两类噪声行**，改动量 ≥10 行 或 ≥5% 判为差异页
- 分母取两侧行数的较大值；`changed = 新增行 + 删除行`（git `--numstat` 口径）
- 比对明细：8.4 侧 1129 篇、8.5 侧 1318 篇；同名 1084；仅 8.4 有 45；仅 8.5 有 234；**完全一致 407**；有改动 677；**达标差异页 306**（其中 273 篇由 ≥5% 触发，33 篇仅靠行数达标）
- 改动量最大的页面：`tidb-lightning/tidb-lightning-configuration.md`（978 行）、`ticdc/ticdc-debezium.md`（845）、`ticdc/ticdc-changefeed-config.md`（825）、`tiflash/tiflash-configuration.md`（786）
- 差异页顶层分布：develop 43、releases 26、ticdc 20、dm 19、sql-statements 19、tiup 12
- 决策说明（2026-10-14 定稿）：**保留 docs-cn 8.5 全量**，另把差异页的 8.4 版单独落一个目录。依据是「版本混淆」要在语料里同时存在新旧两版才有真实素材；8.5 是概念类问题的 ground truth 主力，不删。

### asktug（社区问答）

- 落点 `corpora/tidb/asktug/`：**5009 篇 / 25 MB / 9.61 M 字符**
- 来源：`asktug.com` Discourse JSON API；只取带「已采纳答案」的主题，枚举到 5009 个即止
- 每篇结构：问题（第 1 楼）+ 已采纳答案 + 其他回复（过滤 <40 字的短回复），单篇上限 16000 字符
- 已采纳答案缺失于首屏时，回落到 `/t/{id}/posts.json?post_number=N` 单独取该楼
- 抓取结果：新增 5005、已存在跳过 4、**失败 0**
- 附：`_meta/asktug_topics.jsonl` 保留了枚举到的**全部主题**（含未采纳的），可作「真实中文 query 来源」与困难负例来源

### tidb-net（社区专栏）

- 落点 `corpora/tidb/tidb-net/`：**2536 篇 / 35 MB / 17.43 M 字符**
- 来源：`tidb.net/blog`（Next.js 页面，正文在 `__NEXT_DATA__` 的块级 AST 里，需自行还原为文本）
- 上游共 3076 篇 / 154 页
- **干货率 82.1%**：判定 2990 篇 → 本轮写入 2455 篇，加首轮抽样 81 篇，合计 2536 篇
- 非干货主因：分类=社区与动态 281、技术信号词不足 192、正文过短 43、标题像活动/通知 19
- 判为干货的标准：非「社区与动态」分类、标题不含活动/招募词、正文 ≥600 字、技术信号词命中 ≥5 个
- 抽检样本（均为长文，含实操记录）：`TiDB 7.5 医院接口高频轮询 SQL 的慢查询排查与索引优化记录`（12039 字）、`TiDB Operator — Kubernetes 部署实战`（12520 字）、`热点 Region 逼停了写入：一次 TiDB 写入性能雪崩的 6 小时排查`（3113 字）

## 三、规模与许可（2026-10-14 定稿）

### 规模：维持，不压缩

- 对外口径：**约 1 万文档 / 近 10 万 chunk**（实测 9169 篇 / 约 21.4 M token / 约 9.8 万 chunk）。不写原目标 5 万。
- `docs-cn-v8.4/` 的 306 篇是「版本混淆」失败模式唯一的语料来源，必须留。
- `tidb-net/` 不做浏览量截断 —— 截断会把第三源砍弱。
- embedding 是一次性成本；评测耗时与库规模无关。

### 差异页留法：维持现状

- `docs-cn/`（8.5 全量）+ `docs-cn-v8.4/`（306 篇差异页的 8.4 版）。
- 「删掉 8.5 侧未达标页面」不在方案内 —— 8.5 是概念类问题的 ground truth 主力。

### 许可：语料不公开

- `corpora/tidb/` 整目录写进根 `.gitignore`，不进公开仓库。
- 公开仓库只保留：`scripts/fetch_tidb_corpus.py`、`scripts/tidb_version_diff.py`、`corpora/README.md` 的来源声明、本记录。
- 依据：`docs-cn` 是 CC BY-SA 3.0（ShareAlike 会传染到衍生作品）；AskTUG 与 tidb.net 是用户生成内容，版权分散在各发帖人/作者，无法逐条取得再分发授权。
- 与 `experiments/chroma_db/` 不入库同理；语料本体本地保留，随时可重抓。
- 已核验：`git check-ignore -v corpora/tidb/...` 命中 `.gitignore:23`；`git ls-files corpora/tidb` 返回 0。

## 五、复现命令

```bash
# 官方文档（最新稳定版）
python scripts/fetch_tidb_corpus.py docs

# 另一版本（用于差异比对，落临时目录）
python scripts/fetch_tidb_corpus.py docs --branch release-8.4 --dest <临时目录>

# 版本差异页识别（输出清单 + 计数，并把旧版正文拷到 docs-cn-v8.4/）
python scripts/tidb_version_diff.py --old <临时目录> --new corpora/tidb/docs-cn \
    --copy-changed-old corpora/tidb/docs-cn-v8.4

# 社区问答 / 社区专栏
python scripts/fetch_tidb_corpus.py asktug --target-solved 5000
python scripts/fetch_tidb_corpus.py tidbnet

# 计数
python scripts/fetch_tidb_corpus.py stats
```

## 六、续跑与幂等

- 三条抓取命令都可重跑：已落盘的 `.md` 直接跳过，不重复请求。
- `_meta/asktug.state.json` 记录 `enum_last_page`（列表翻到第几页）、`fetch_last_topic_id`（详情抓到哪个主题）；`_meta/tidb-net.state.json` 记录 `enum_last_page`、`fetch_last_slug`。索引按页**增量追加**，中断后从断点页继续。
- `_meta/tidb-net-judged.jsonl` 记录每篇的判定结果（含被拒稿），避免重跑时把非干货文章再抓一遍。
- 实测重跑：AskTUG 二次运行 `新增 0 / 跳过 5009 / 失败 0`，全程无网络重抓。
- `docs` 子命令不做断点续传（打包下载约 30 秒，重跑代价可忽略），但重复运行结果一致。

## 七、踩到的坑

- **`git clone --depth 1` 走本机代理只有约 75 KB/s**（9 分半只下了 41 MB），而同一内容的 codeload 打包下载只要约 30 秒 → 取另一版本分支改用打包方式，产物一致。
- **Git Bash 会把 `/query` 这类参数当路径转换**，导致 `powercfg /query` 报「参数无效」；校验 Windows 命令改用带 `-` 的写法或直接在 PowerShell 里跑。
- **脚本把「条数」当退出码返回**（`sys.exit(1318)`）会让任务被误判为失败，实际是成功的。
- `corpora/<语料>/_meta/` 里的文件若用 `.md` / `.txt` 后缀，**会被 `iter_supported_docs` 当成语料扫进索引** —— 该目录只允许非受支持后缀（`.source` / `.json` / `.jsonl` / `.log` / `.list`）。已实测：`iter_supported_docs("corpora/tidb")` 返回 **9169 篇，`_meta` 零误入**。
