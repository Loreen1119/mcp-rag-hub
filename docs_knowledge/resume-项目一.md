## 项目一：RAG 智能知识检索系统

**时间：2025.12 - 至今 | GitHub 开源**

**技术栈：** Python / ChromaDB / LangGraph / BM25 / FastMCP / Cross-Encoder / Streamlit / NetworkX

### 项目背景

面向企业知识库中关键词匹配与语义搜索难以兼顾，以及实体关联类查询的检索盲区，设计并实现关键词 + 向量 + 实体共现图三路混合检索系统，并封装为 Agent 可调用的检索微服务。

### 核心职责

1. **三路混合检索与融合排序：** 实现 BM25 + ChromaDB + 实体共现图三路并行召回，采用 RRF 算法融合消除得分量纲差异；集成 Cross-Encoder 精排并限制输入 Top-N 候选数以平衡精度与 CPU 延迟，语义类查询 MRR 达 0.967。
2. **实体共现图补盲：** 基于 Jieba 词性标注与 TF-IDF 抽取实体，利用 NetworkX 构建共现图实现子图遍历；设计精确/模糊二级匹配与距离衰减评分，独立图检索 Precision@5 达 0.893（较向量提升 17%），延迟仅 0.85ms。
3. **文档解析与 Token 级切片：** 基于 tiktoken 统一计数对齐模型编码窗口做贪心滑窗切片，同时通过 Markdown 标题栈面包屑为每个 Chunk 注入章节溯源信息，配合编码降级检测链兼容企业遗留文档。
4. **评测体系与 Agent 微服务化：** 自建三分层 Golden Test Set 自动化评测管线；基于 LangGraph 实现含自感知改写的条件路由 Agent，并通过 FastMCP 封装为标准 Tool 接口。

### 项目成效

- 三路混合检索全管线 **MRR 0.967**
- 实体共现图独立 **Precision@5 0.893**（向量检索 0.760），混合类查询较向量检索 MRR 0.900 实现显著补盲
- 全链路延迟 **395ms**（本地 CPU），瓶颈在 CE 精排（373ms），图检索仅 0.85ms
- 完整开源，模块化设计支持各环节独立替换
